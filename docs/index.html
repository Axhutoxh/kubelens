Build from source

Up and running
in three steps.

1

Install the toolchain. Rust (stable) and bun. On Linux also libwebkit2gtk-4.1-dev; Windows and macOS already ship a WebView.

2

Build. On Windows run scripts\build.bat; on macOS / Linux run bun x @tauri-apps/cli@2 build. Installers land in target/release/bundle/.

3

Launch. Kubellens auto-discovers every context in ~/.kube/config. Pick one and go.
