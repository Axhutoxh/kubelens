Features

Everything you need to
run a cluster.

Inspect, edit, scale and debug every core Kubernetes resource from one fast, keyboard-friendly window.

Architecture

One binary. Zero runtime baggage.

The React UI is embedded straight into the Rust executable. An Axum server on Tokio talks to your clusters and streams data back over SSE.

Get started

Up and running
in three steps.

1

Install the toolchain. Rust (stable), bun, and the WebView2 runtime (ships with Windows 11).

2

Build. scripts\build.bat compiles the React UI and packages an NSIS installer into release\.

3

Launch. Kubellens auto-discovers every context in ~/.kube/config. Pick one and go.
